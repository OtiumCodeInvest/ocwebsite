Otium Code LLM — Autoregressive Transformer Architecture

The Otium Code language model is a 24-layer bilingual (Danish and English) decoder-only Transformer designed for long-horizon reasoning across a 32,768-token context window. The architecture combines interleaved local-global self-attention, bounded circular key-value memory, squared-ReLU feed-forward networks, and formal pushdown-automaton decoding constraints.

End-to-End Forward & Decoding Formulation

Traces the complete computation from contiguous token ingestion and embedding lookup through 24 hybrid self-attention layers to soft-capped, grammar-constrained output logits.

01 · INPUT GATHER E ∈ ℜ32,768 × 1,536

Lexical Stream & Gated Bigram Embedding

Documents are packed into a lossless contiguous stream with block-diagonal causal isolation. Token indices gather rows et−1 and et from the untied embedding matrix E, incorporate gated adjacent-token context, and normalize to h0.

02 · HYBRID ATTENTION SCHEDULE 18 Local (S) · 6 Global (L)

Interleaved Local-Global Self-Attention

The 24 layers follow a periodic four-layer SSSL schedule: 18 local sliding-window layers (W = 2,048) model fine-grained positional structure, while 6 full-context layers aggregate global information across 32,768 tokens.

03 · RESIDUAL SUBTRACTION hmid = h11

Mid-Network Residual Backout

To prevent early-layer lexical and positional features from saturating the final representation, the residual state hmid at the network midpoint (l = 11) is retained and subtracted with learned weight λb prior to final normalization.

04 · BOUNDED KV MEMORY t mod (W + 1)

Circular Key-Value Cache & Rotary Scaling

During autoregressive generation, the 18 local layers maintain a bounded circular buffer of capacity W + 1 = 2,049, reducing long-context KV memory by 69%. Queries and keys apply RMS normalization and Rotary Position Embeddings (θ = 105 → 5×105).

05 · NON-LINEARITY & ALIGNMENT ReLU2 · RFT · GRPO

Squared-ReLU FFN & Policy Optimization

Feed-forward blocks apply squared rectified linear units ReLU(x)2, inducing high activation sparsity. Matrix parameters are updated via polar-orthogonalized momentum, followed by K=4 rejection sampling and group-relative policy optimization.

06 · OUTPUT PROJECTION Wu ∈ ℜ1,536 × 32,768

Unembedding & Hyperbolic Tangent Soft-Capping

Normalized final states project through an untied unembedding matrix Wu and undergo smooth logit soft-capping z = C · tanh(u / C) at C = 15.0 to bound logit magnitude and stabilize cross-entropy training.

07 · FORMAL GRAMMAR CONSTRAINTS Pushdown Automaton

Automaton-Constrained Decoding & Symbolic Evaluation

Prior to sampling, a byte-level pushdown automaton evaluates vocabulary transitions against context-free grammar rules, assigning −∞ to syntactically inadmissible tokens and invoking exact symbolic evaluation on completed expressions.
