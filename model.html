Otium Code LLM — Network Primitives & Architecture

Otium Code LLM is a bilingual (Danish and English) autoregressive Transformer engineered for 32K long-context reasoning, lossless continuous FIFO token streaming, C++20 grammar-constrained decoding, live AST calculator execution, and rejection-sampled reinforcement learning.

Complete Network Overview

Shows the full forward and decoding path from continuous token ingestion and input embedding gather through the 20-layer hybrid stack to grammar-constrained output logits.

01 · INPUT GATHER wte (32,768 × 1,280)

Continuous FIFO Stream & wte Gather

Tokens enter from a lossless FIFO stream (overlap K=0/64, intra-doc boundary mask). Token IDs gather vector rows $e_{t-1}, e_t$ from the untied wte matrix, mix bigram context via smear_gate, and normalize to $x_0$.

02 · 20-LAYER SSSL SCHEDULE 15 Sliding · 5 Full

20-Layer Hybrid SSSL Attention Spine

Five blocks of four layers: 15 Sliding Window (S) layers capture local positional order, while 5 Full Global (L) layers (L03, L07, L11, L15, L19) attend across the entire 32K sequence.

03 · RESIDUAL HIGHWAYS & VE x₀ · VE · Backout

x₀ Highway, Value Embeddings & Backout

Each layer mixes initial $x_0$ via resid_lambdas and x0_lambdas. Odd layers inject gated token Value Embeddings (VE) into attention $V$, and Layer 10's residual is subtracted via backout_lambda.

04 · CIRCULAR RING KV CACHE slot = pos % (W + 1)

Bounded Ring-Buffer KV & 32K RoPE

During decoding, the 15 S layers wrap writes inside a fixed $(W + 1)$ circular ring buffer rather than growing linearly, paired with $1.2\times$ QK-RMSNorm and $\theta = 100\text{k} \rightarrow 500\text{k}$ RoPE.

05 · ReLU² MLP & RFT / GRPO K=4 Judge · MuonAdamW

ReLU² Sparsity, Rejection Sampling & RL

MLPs apply squared ReLU(x)² for natural activation sparsity. Post-training runs $K=4$ Rejection Sampling with live calculator execution and on-policy GRPO RL ($A_i = r_i - \mu_r$).

06 · OUTPUT LOGITS & SOFTCAP 1,280 → 32,768

Untied lm_head & Tanh Logit Softcap

Final normalized hidden states project through the untied lm_head to 32,768 vocabulary logits and are smoothly bounded by $15.0\cdot\tanh(z/15.0)$ with chunked cross-entropy training.

07 · C++20 CONSTRAINED DECODING < 0.5 ms PDA Mask

C++20 Pushdown Automaton & AST Tool

A native C++20 byte automaton validates all 32,768 next tokens per step across 5 grammar modes, setting illegal logits to -∞ and intercepting <|tool_end|> for sandboxed AST math evaluation.
