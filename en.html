Otium Code is a software consultancy firm. We specialize in developing machine learning models, implementing end-to-end AI products from data collection, building annotation tools, training neural networks, and optimizing inference. Most recently, we delivered a large-scale solution converting architectural drawings into precise CAD models.

We are open to various collaboration models, ranging from traditional work-for-hire to investing time for potential upside. Our primary criteria for taking on new projects is the technical challenge involved.

Over our 25+ years of experience we have transitioned from AAA game development to training ML models for image analysis back in 2016. We are full stack programmers and our core programming languages include C, C++, and Python, alongside highly optimized, low-level assembly programming and optimizing models for embedded systems. We also have experience with PCB microcontroller design and firmware development.

Selected Projects

Floor Plans to CAD

System for converting hand-drawn or rendered pixel-based images of architectural floor plans to CAD format. This included locating symbols (Doors/Windows) and general wall structures. We developed an end-to-end AI infrastructure starting with data collection and custom annotation tools using foundation models. The AI models combined U-Net for segmentation/graphs and ViT for element analysis. Executed via a custom secure RPC server (PyTorch) to allow low hardware requirements for the end user, with a client side in C++.

Robotics RF Sensors

Low latency large-scale robotics RF sensors to Python infrastructure. Included RF design using forward error correction (Reed-Solomon) for ultra-low glass-to-glass latency. The platform collected camera and LiDAR data directly into GPU memory for fast Python inference on the host computer. Sensors ran on a Pi CM4 with a custom RF board (designed in KiCad). The infrastructure was written in C/C++ with a Python AI endpoint.

UWB Positioning System

Designed PCB (KiCad) for base stations and tags for <10cm triangulation of position for indoor robots. The system was built around an STM microcontroller and the DW3120 IC from Qorvo. We wrote custom firmware and integrated it directly with a Pi CM4 without any additional microcontrollers. The system was mainly written in C.

Factory Floor Triangulation

Multicamera triangulation system for humans and robots based on a pose ML network. It locates body/robot parts to reconstruct poses and global positions relative to cameras. Designed to define virtual areas for automated observation (e.g., verifying safety equipment or validating entities in zones). Proprietary ML analyzed images locally, sending 2D pose data to a central PC for triangulation. Embedded execution (NVIDIA Jetson / TensorRT) allows scaling to massive areas like airports.

Smart City Solutions

Privacy-by-design camera solution for counting bicycles, pedestrians, and cars, sending only anonymized data from the local sensor. Implemented on the NVIDIA Jetson TX2 platform using a YOLO architecture model. We built a custom ML primitives framework for fast CPU/GPU inference. The solution included time-travel estimation to match cars across multiple cameras using a GDPR-safe embedding algorithm.

Face Statistics & Recognition

A system to simplify keycard check-ins by matching facial features against an employee database, also used for matching unknown-against-unknown for public traffic statistics. Featured a custom embedded webserver and a proprietary timeseries database written entirely in C++. The hardware utilized a custom embedded system running two Linux units with an FPGA-based inference accelerator.

Inner Ear Scanner

A scanner for the inner ear with 200-micron precision for hearing aid fitting. Used a head-fixated fiducial to estimate the camera's 6-DoF extrinsic pose via computer vision. The 3D point cloud generation utilized laser line triangulation, and the mesh was generated with Poisson surface reconstruction. The entire pipeline, from image retrieval to rendering, was implemented in C++, optimized with SIMD, and rendered in OpenGL.
