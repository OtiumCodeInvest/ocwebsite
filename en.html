We specialize in developing machine learning models, implementing end-to-end AI products from data collection, building annotation tools, training neural networks, and optimizing inference. Selected Projects

Floor Plans to CAD

System for converting hand drawn or rendered pixel based images of architectural floor plans to CAD format. This task included locating symbols Doors/Windows and the general wall structures of the floorplans. We developed an end to end AI infrastructure starting with data collection and annotation. Then the data was annotated with custom tools using foundation models for semi automated annotation. The AI models for the conversion was a combination of network architectures U-Net for segmentation and graph. ViT for elements analysis. The execution of the AI was done with a custom secure server RPC to allow for low hardware requirements for the end user. The training and server inference was done in pyTorch and the client side was done in C++.

Robotics RF Sensors

Low latency large scale robotics RF sensors to python infrastructure. This included RF design using forward error correction (solomon reed) for ultra low glass to glass latency. The platform collected the camera and lidar data directly in GPU memory for fast inference in Python on the host computer. The sensors on the robots was a Pi CM4 with a custom sensor RF board. The infrastructure was written in C/C++ and the AI endpoint for the developers using the system in Python. The custom PCB designed in KiCad

UWB positioning system

Designed PCB for base stations and tags for <10cm triangulation of position for indoor robots. The system was built around an STM microcontroller and the DW3120 IC from Qorvo. We wrote custom firmware and direct integration with a Pi CM4 without any additional microcontroller. The system was mainly written in C. The custom PCB designed in KiCad

Large scale pose triangulation

Multicamera triangulation system for full pose 3D reconstruction for persons and robots. Based on pose ML network structure to locate body parts and robot parts to reconstruct pose and global position relative to the cameras. The system was designed to define virtual areas for automated observation. It could be for security with a check for the correct safety equipment or to validate that an entity was present in a certain location. The system was running our proprietary ML to analyze the images on the camera and the 2D pose information was then sent and triangulated on a central PC along with ROI for extended analysis. The system could potentially cover a giant area like an airport due to the embedded ML execution. The embedded system was based on NVIDIA Jetson. The inference was implemented with TensorRT.

Smart City

Smart city solution for counting bicycles, pedestrians and cars in a privacy by design camera that only sends anonymized data from the local camera sensor. This was implemented using NVIDIA Jetson TX2 platform. The ML model was based on the YOLO architecture. We made our own ML primitives framework for fast CPU/GPU inference. The solution included a time travel estimation that could match cars from multiple cameras with a GDPR safe embedding algorithm.

Face statistics

A system to simplify keycard check-in matching facial features to identify an employee against a database. Also used for matching unknown against unknown for public traffic statistics. Custom embedded webserver for interface and entire platform including proprietary timeseries database was made in C++. The hardware was a custom embedded system with two linux units with a FPGA based inference accelerator.

Inner Ear Scanner

Ear scanner of the inner ear with 200 microns precision for hearing aid fitting. The setup used a fiducial fixated on the head to estimate the camera's 6-DoF extrinsic pose using computer vision. The 3D point cloud generation was implemented using laser line triangulation. The triangle mesh was generated with poisson surface reconstruction and the entire pipeline was optimized from image retrieval to mesh rendering. The project was implemented in C++ and optimized with SIMD and rendered in OpenGL.
